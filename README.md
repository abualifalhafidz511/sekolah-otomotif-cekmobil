# sekolah-otomotif-cekmobil

Platform ujian seleksi online, pendaftaran calon peserta didik baru (PPDB), penilaian otomatis, dan publikasi hasil kelulusan sekolah otomotif.

## Fitur Utama
- Sistem ujian seleksi online interaktif
- Formulir pendaftaran calon peserta didik baru
- Penilaian otomatis terintegrasi
- Dashboard dan publikasi hasil tes

## Menjalankan Proyek Secara Lokal

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Setup Environment:**
   Salin file `.env.example` menjadi `.env` dan masukkan konfigurasi yang diperlukan:
   ```bash
   cp .env.example .env
   ```

3. **Jalankan Development Server:**
   ```bash
   npm run dev
   ```

   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
